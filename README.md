# B&C

## Как собрать проект по макету из Figma

Сейчас Figma-ссылка требует авторизацию (возвращает 403), поэтому самый быстрый путь — экспортировать кадры макета в PNG и положить их в `Assets.xcassets`.

### Шаги

1. В Figma экспортируйте нужные Frames в **PNG** (лучше @2x/@3x).
2. В Xcode откройте `B&C/Assets.xcassets` и добавьте изображения (Drag & Drop).
3. Откройте `B&C/Features/Design/DesignFrame.swift` и перечислите ассеты в `DesignFrame.all`.
4. Запустите приложение → `B&C` → `Открыть кадры макета`.

После того как кадры будут в проекте, я:
- разложу экраны по папкам `Features/*` по диаграмме,
- настрою навигацию и состояния,
- сверстаю UI 1:1 по вашим PNG и Dev Specs.
